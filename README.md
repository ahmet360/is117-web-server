# IS117 Basic Web Server

Ahmet Elci's Express project for the Node.js setup and first web-server assignment.
Built with AI assistance following [Keith Williams's Parts 1-6](https://github.com/kaw393939/is117-basic-web-server).

## Run

Requires Node.js 22 or newer.

```sh
npm ci
npm start
```

Open <http://localhost:3000>, <http://localhost:3000/about>, and <http://localhost:3000/missing-page>.

## Test

```sh
npm test
```
